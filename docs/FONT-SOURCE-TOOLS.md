# Optional localization source tools

29 October 2026. Source preservation only; no new recovery build or tablet test
is recorded here.

`scripts/translate-locales.sh` is an opt-in host helper for public source strings.
It is not called by the build or installed in recovery. It requires the native
locale tool and validates imported responses before retaining generated output.

`src/localization/font-instance.cpp` is a host-only HarfBuzz instancing utility.
It requires the matching HarfBuzz subset SDK. The fallback header is retained
as source for the matching `TrueTypeFont` adapter and is not enabled by this
source import. Default renderer and package behavior remain unchanged.

Generated CJK font bytes are not a new source dependency or shipping asset.
A future integration must pin the original font, retain its license notices
and validate the generated bytes before changing the recovery payload.
